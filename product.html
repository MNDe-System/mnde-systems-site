Product

One boundary before runtime

MNDe is not a monitoring tool. It is not a policy suggestion engine. It is a deterministic enforcement point.

Preflight

Every request is normalized before evaluation.

Unknown fields are rejected. Duplicate keys are rejected.

The same input always produces the same canonical form.

Orbit

Enforcement does not depend on code path.

Orbit ensures the same decision holds across retries, services, and flows.

ARM

Cost and scope are calculated before execution.

Limits are applied before any resource is consumed.

RAM0NA

Returns a single decision. Allow or refuse.

Each decision is signed and stored.

Given the same input and policy, the output is identical.
